# Project RollingPaper

In Korea, there is a traditional game in our culture called 'Rolling Paper'. This is where you have a sheet of paper where people can anonymously write about things they always wanted to say to you, done in
occasions such as graduations or birthdays.

This project is created to digitilise that.
